THE CELLS BEHIND THE CHART

Readable. Editable. Yours.

import polars as pl
import altair as alt

sales = pl.read_csv(DATA_DIR / "sales.csv")
revenue = sales.group_by(
    "month", "region"
).agg(pl.col("revenue").sum())

alt.Chart(revenue).mark_bar().encode(
    x="month:N", y="revenue:Q",
    color="region:N", xOffset="region:N",
)

    Create a workspace

    A folder for your data, notebooks and settings.

    mkdir my-analysis
cd my-analysis
uvx hailer init
  2. 2

    Connect your model

    Sign in with an OpenAI API key, or configure another endpoint.

    uvx hailer login openai
  3. 3

    Add data. Say hello.

    Put files in data/, then start Hailer. Keep the notebook tab open.

    uvx hailer

KNOW WHERE YOUR DATA GOES

Local files.
A model you configure.

Your analysis runs on your machine. Your messages, code and notebook tool outputs — which can include data samples — go to your configured model endpoint.

By default notebook code runs in a Docker container that sees only your data folder, read-only, with no network; its outputs still go to the model. Running code as you, with your files and network, is an explicit opt-in (unsafe-local).
